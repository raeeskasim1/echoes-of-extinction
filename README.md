# Echoes of Extinction 🌿

**Echoes of Extinction** is an interactive educational website that explores extinct and endangered animals, their habitats, and the threats they face.

The website aims to raise awareness about biodiversity loss and wildlife conservation through visual storytelling.

## Features

- Explore extinct and endangered animal species.
- Search and filter animals.
- Discover animal stories and extinction timelines.
- Save favorite animals to field notes.
- Learn about the causes of extinction.
- Test your knowledge with an interactive quiz.
- Responsive design for desktop and mobile devices.

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

Download or clone the repository and open `index.html` in your browser.

## Purpose

To create an engaging learning experience that highlights the importance of protecting wildlife and preserving biodiversity.
